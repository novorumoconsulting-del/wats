# WhatsApp Sales Funnel Application

This repository contains a comprehensive application designed to facilitate sales funnel management via WhatsApp integration. 

## Features
- WhatsApp Integration
- Contact Management
- Message Scheduling
- Bulk Messaging
- Auto Labeling and Contact Saving

## Getting Started

1. Clone the repository
2. Install dependencies
3. Configure your environment variables using `.env.example`
4. Run the application

## Dependencies

- `whatsapp-web.js`
- `dotenv`
- `express`
